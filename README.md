# QA Automation Practice – Playwright

This repository contains my practice automation scripts using:
- Python
- Playwright
- Pytest

## Scenarios Covered
- Login functionality testing (valid & invalid)
- Button validation
- Checkbox validation
- Assertions and locators
- Test Navigation Bar

## Test Website
1) https://the-internet.herokuapp.com/
2) https://ultimateqa.com/automation


## How to Run Tests
1. Install dependencies
   pip install -r requirements.txt
2. Run tests
   pytest
